# 页面原型

当前为依据 V1.3 修订版制作的第一版静态 PC Web 原型。临时品牌名“拾作”和示例内容用于表达视觉及业务场景，不代表正式数据或最终品牌决定。

当前需求依据已更新为 [V1.4 MVP 版](../requirements/requirements.md)，原型尚未适配。页面仅供布局与操作意图参考；与当前需求不一致的功能和规则以需求正文为准。

## 阅读入口

- [原始原型说明](assets/原型说明.md)：视觉方向、完整页面清单、页面联系及阅读边界。

## 使用约定

- `assets/` 完整保留原 `原型图/` 的原始文件；原始说明中出现的旧需求文件名表示制作来源，当前需求入口见上方链接。
- 页面示例展示不同时间和状态，不应拼成同一时刻的系统数据。
- 未单独绘制的页面仍按需求保留，不能据此缩减业务范围。
- 后续 UI 规范放在 `docs/design/`，原型本身不替代接口、权限和状态设计。
- 新增或更新原型时同步维护本索引，说明对应需求版本；已有相关业务功能任务时再更新该任务，纯原型调整不创建开发任务。
