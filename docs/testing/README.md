## 最小记录格式

复制下面的格式填写即可，无需额外模板文件：

```markdown
# T-编号 任务或功能名称测试记录

- 关联任务：链接到对应任务文件
- 环境或前提：仅填写影响结果的必要信息

| 日期 | 测试项与命令或操作 | 结果 | 简要说明 |
| --- | --- | --- | --- |
| YYYY-MM-DD | 填写实际检查内容 | 通过 / 失败 / 未执行（三选一） | 失败写原因；未执行写原因；复测说明处理结果 |
```

仅凭实际执行结果填写“通过”或“失败”；未运行的项目写“未执行”。日志仅摘录必要报错，不保存大量原始输出或真实个人信息。
