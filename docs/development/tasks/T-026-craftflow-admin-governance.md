- 关联设计：[前端重做开发指南](../../design/frontend-rebuild-guide.md#第-6-批--后台管理与内容治理)

## 验收条件

- 后台使用统一布局。审核、售后及查询队列的详情可直接访问，筛选与页码随返回恢复。
- 看板展示服务端统计和更新时间。用户可检索，暂停及恢复留痕，两种暂停状态独立，旧单可继续履约。综合订单按条件查询，异常与售后优先；资金查询可导航到原订单。
- 四类举报按类型进入对应核查与处置流程，历次处置留痕。用户从「我的举报」或通知进入详情，按资格补证或异议。
- 作品私稿仅作者可见。后台查询和图片签名只使用该角色有权访问的材料，恢复作品时校验下架后有无未提交修改。
