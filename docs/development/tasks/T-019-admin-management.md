# T-019 后台管理模块补齐

- 状态：待验收
- 更新日期：2026-11-20
- 需求依据：[V1.5 需求 4.9、4.1.3、R-08、R-09、UC-36](../../requirements/requirements.md)
- 关联设计：沿用现有用户、订单、资金及 `operation_log` 表，不新增迁移

## 目标与范围

补齐后台基础数据看板、用户管理和订单综合查询；为退款及结算专项记录补时间、金额筛选；提供创作者本人暂停/恢复接单入口。管理员暂停新业务与本人暂停接单始终独立。

## 验收条件

- 管理员访问看板可查看用户、新增用户、认证创作者、新增认证、作品、需求、订单、模拟支付、模拟退款、待结算、已结算及待办统计，并显示更新时间；新增统计按北京时间日期范围查询。
- 管理员可按邮箱、昵称、认证状态分页查询用户，并查看近期关联作品、需求和订单摘要。
- 管理员暂停或恢复用户新业务须填写原因；暂停还须填写恢复条件。操作人、时间、对象、前后状态、原因及恢复条件追加至操作日志。认证状态不变，已存在订单业务不被拦截。
- 认证创作者可本人暂停或恢复接单；更新只影响本人暂停标记，不能解除管理员暂停；管理员恢复也不能覆盖本人暂停选择。
- 管理员可按订单号、状态、类型、创建时间、金额查询现货及定制订单，并查看约定快照、支付/资金、发货、会话和制作记录；退款按申请创建时间、订单实付金额筛选，结算按记录创建时间、实付金额筛选。
- 所有管理接口在服务端校验管理员身份；查询接口只读，不返回不必要的收货或收款快照。

## 设计与改动位置

- 后端新增看板、用户管理、订单查询的 Controller、Service、ServiceImpl、Mapper、DTO/VO；扩展退款及结算查询 DTO/Mapper。
- 前端新增后台看板、用户管理、订单查询页面，扩展退款与结算筛选，并在个人资料提供创作者接单开关。
- 暂停状态变更锁定账号行并复用只追加的 `operation_log`；无需数据库迁移。
- 接口：`GET /api/admin/dashboard`、`GET /api/admin/users`、`GET /api/admin/users/{id}`、`PUT /api/admin/users/{id}/business-pause`、`GET|PUT /api/me/creator-pause`、`GET /api/admin/orders`、`GET /api/admin/orders/{id}`。
