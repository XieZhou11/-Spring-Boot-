## 目标与验收条件

- 买家能管理草稿、公开或定向发布、关闭和复制。创作者能从大厅或邀约进入，返回时保留来源和筛选。
- 创作者能报价、撤回及重报。买家从同一张表比较方案，选本人地址后创建唯一待付款订单。未知结果重试沿用原确认。
- 公开和定向链路均沿用中标原会话，落选会话只读。会话支持图文、历史翻页、已读同步及断线补拉。系统通知可标已读并跳转对应业务。
