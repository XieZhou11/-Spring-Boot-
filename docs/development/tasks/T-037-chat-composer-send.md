# T-037 聊天输入与发送

- **状态** 已完成
- **更新日期** 2026-11-28
- **依据** 用户反馈及 [V1.5 会话规则](../../requirements/requirements.md)

聊天输入框隐藏滚动条，长文仍可滚动。Enter 发送文字，Shift+Enter 换行，输入法的候选确认继续交给浏览器。选图完成后自动发送独立图片消息，每次最多三张，单张最多 5 MB。

使用现有消息及图片上传接口。图片批次须全部上传成功才能提交消息。文字和进度引用作为独立草稿保留，未知结果使用原请求重试。

Edge 定向回归、隔离后端联调、ESLint 和生产构建均通过。 [测试记录](../../testing/T-037-chat-composer-send.md)
