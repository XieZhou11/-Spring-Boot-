## 目标与验收

- 评论举报与作者删除依次锁定作品和评论。举报先完成时两项均成功，作者先删除时举报返回 404。
- 评价、举报和补证的越界图片编号返回字段级 400。按存量编号确定上限，页面展示图片缩略图及已选张数。
- 定制打卡及包装发货需要 1–6 张当前阶段实拍图。缺图时返回 400，节点、订单与相关记录保持提交前状态。现货凭运单发货，节点补充可以只填文字。
