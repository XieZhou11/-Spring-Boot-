## 目标与验收条件

- 资料和头像可独立保存，地址可维护并保持唯一默认，买家和创作者切换只影响当前会话。
- 创作者能上传材料申请、撤回和补正，管理员在审核双栏对照材料、给出结论并通知申请人。认证通过后收款资料只读。
- 创作者能从草稿走到审核上架。交易设置即时生效，图文修改重审。后台品类维护和审核使用真实接口。
- 买家能浏览、点赞、收藏、关注与图文评论，持久化状态在刷新后保持一致。
- Chrome 和 Edge 在 1366 像素视口可完成主要操作。

## 已知业务差异

- §4.2.2 规定未提交草稿仅作者可见。后台作品查询与详情目前仍可读取草稿。
- §4.9.1 要求更正时保留原结论。入驻与作品审核接口目前只支持原结论的幂等重试。两项差异由后端分别核实和补齐。
