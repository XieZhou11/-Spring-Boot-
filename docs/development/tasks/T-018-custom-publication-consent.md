# T-018 定制成品公开授权与案例发布

- 状态：已完成
- 更新日期：2026-11-23
- 需求依据：[V1.5 需求 4.2.6、UC-38、UC-39、附录 A.7](../../requirements/requirements.md)
- 关联设计：[数据库表结构：trade_order、work](../../design/数据库表结构.md)

## 目标与范围

实现定制订单创作者申请公开成品案例、买家明确同意或拒绝，以及创作者手动整理并关联发布案例。沿用现有订单授权字段、作品来源订单字段和作品审核流程，不自动复制订单图片或订单资料。

## 验收条件

- 仅已完成的定制订单创作者可以申请；仅本订单买家可以明确回复，记录申请/回复时间并分别通知对方。
- 未回复、已读或聊天内容不能作为授权；越权请求拒绝，重复申请/回复不覆盖状态、不重复通知。
- 仅本人买家已明确同意的定制订单可关联作品；来源订单首次关联后不可清除或替换，作品修改和提交审核继续校验授权。
- 案例需手动编辑并通过正常作品审核；禁止开启现货销售，仍可接受新的同类定制。
- 授权不改变订单、退款、评价或结算状态；对外不提供订单地址或聊天记录。

## 设计与改动位置

- 后端订单授权服务、订单详情接口、通知事件、作品保存/提交校验及来源订单读写。
- 前端订单详情授权操作、作品编辑器授权订单选择和现货开关提示。
- 沿用 V1 已有 `trade_order` 授权字段和 `work.source_order_id`，不新增迁移。
- 接口：`POST /api/orders/{id}/publication-consent` 申请；`PUT /api/orders/{id}/publication-consent` 携带 `decision=APPROVED|REJECTED` 回复；`GET /api/me/approved-publication-orders` 查询可关联订单；作品创建/保存/提交请求携带可选 `sourceOrderId`。

## 验证结果

- 总体结果：通过；2026-11-23 独立验收浏览器 E2E 2 项通过。
- 测试记录：[T-018 测试记录](../../testing/T-018-custom-publication-consent.md)
- E2E 覆盖：创作者申请公开 → 买家明确同意 → 已授权订单进入可关联列表 → 创建案例关联来源后来源下拉与现货开关均禁用；买家明确拒绝后状态保持 REJECTED，重复回复返回 200 但不覆盖状态，未授权订单不进入可关联列表。

## 审查与遗留问题

授权双方权限、拒绝与重复操作、案例来源归属/授权、来源关联不可变、现货销售禁用均由浏览器 E2E 覆盖并通过。云端 OSS 图片与真实公网邮件不在本任务验收范围。
