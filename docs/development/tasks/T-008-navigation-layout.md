- 关联设计：[原型 01、07、08、09](../../prototypes/README.md)。采用页面布局和操作意图，业务规则仍以 V1.5 为准。

## 目标与范围

管理员默认进入后台，固定左侧导航，作品/入驻审核以队列和材料详情双栏操作。普通用户使用清晰的一级导航，需求管理独立，沟通与系统通知统一进入消息中心，个人中心只保留资料、地址与入驻信息。清理重复辅助文案，补齐首页发布需求入口。复用现有服务端接口、权限和真实会话，不增加未实现的交易、统计或管理功能。

## 验收条件

1. 管理员登录默认进入作品审核；后台没有前台搜索及交易导航，左栏固定且菜单随详情路由保持高亮。
2. 作品和入驻审核选择材料后，列表与详情同时存在；筛选、分页与浏览器回退保留上下文；提交结论后刷新队列，保留权威结果与失败恢复。
3. 普通买家从首页直接发布需求，也可从一级导航进入我的需求；个人中心不再包含需求和沟通。
4. 消息中心包含需求沟通和系统通知；沟通采用会话列表与当前会话并排，保留图文、未读、归档、断线恢复及离开保护。
5. 创作者有工作台、需求大厅和邀约入口；普通买家不出现需要创作者资格的入口；管理员不出现发布需求操作。
6. 原个人中心需求/消息链接兼容跳转，查询参数及锚点保留；未登录和越权访问继续由路由守卫和后端约束。
7. 桌面显示双栏，窄屏可先选择列表再看详情，无页面横向溢出；类型、lint、构建和相关真实浏览器回归通过。

## 设计与改动位置

前端角色布局、导航、路由与审核/消息页面。审核使用父路由保留队列，子路由承载详情；消息同样通过父路由保留会话列表。需求使用 `/my-requests`，消息使用 `/messages`，旧 `/account` 路径重定向。后台默认 `/admin/works`，管理员可从后台进入 `/discover` 查看前台作品。
