# T-035 交易会话界面闲鱼式改造

- 状态：待验收
- 更新日期：2026-11-27
- 需求依据：[V1.5 §4.7 需求沟通与交易会话相关章节](../../requirements/requirements.md)；界面参照用户提供的闲鱼交易对话截图，仅对齐视觉与交互组织，不引入闲鱼独有业务（复购、已读回执等）

## 目标与范围

在 `astudio/dev` 分支的独立 worktree 中，把交易会话页（会话列表 + 会话详情）向闲鱼式交易对话体验靠拢，只改本系统已有元素，保留未读相关能力。

包含：

- 会话 VO 增加对方头像签名、订单金额快照与来源作品主图（服务端复用 `AvatarService`、订单快照与 `WorkImageService`，无数据库结构变更）。
- 消息区补双方圆形头像：对方头像使用会话 VO 的短时签名，本人头像读取个人资料；无头像时昵称首字占位。
- 时间戳收敛为分组显示：同分钟连续消息只显示一次，跨天插入居中日期分隔；不改变已读推进与 `data-seq` 逻辑。
- 会话详情顶部改为交易卡片：订单会话展示订单标题、金额、状态与入口按钮；需求会话展示需求标题与状态；无交易上下文保持现状。
- 输入区从表单式改为聊天条式：移除字段标题、图片上传收敛为图标按钮、已选图片改为小缩略图、发送按钮改胶囊主色。
- 气泡配色使用站内琥珀色系，贴近闲鱼黄色方向，不照抄 `#FFE600`。

不包含（未做）：

- 已读回执（“已读”显示）：`ChatMessageVO` 无对方已读序号，需新增后端语义与推送事件，属需求级扩展，待用户单独确认。
- 闲鱼式“再次购买/议价/电话/转账”等本系统不存在的交易操作。
- 任何未读机制的变更：未读徽标、隐藏标签页不消耗未读、已读上报、左栏选中态全部保留。
