# T-027 CraftFlow 第 7 批 · 全站联验与新版切换

- 状态：已完成
- 更新日期：2026-11-25
- 需求依据：[V1.5 MVP](../../requirements/requirements.md) §5.3、§8，UC-01 至 UC-40
- 关联设计：[前端重做开发指南](../../design/frontend-rebuild-guide.md#第-7-批--全站联验与新版切换)

## 验收条件

- 买家、创作者和管理员从新版入口操作。页面在 Chrome 与 Edge 的 1366 像素视口可读、可操作，表单与异步操作有对应反馈。
- 旧书签、登录回跳、筛选返回和通知深链接可用。举报列表及两类详情使用公共布局。
- 隔离后端环境覆盖跨角色主流程、同件现货并发购买及 V1.5 验收要点。通过前端静态检查、生产构建及全量浏览器回归。

## 实施步骤

- [x] 逐页走查、修复缺陷并启用统一新版布局。
- [x] 验证交易、消息、举报、后台及资金查询的跨角色流程。
- [x] 完成全量回归、生产预览及独立审查。

## 验证结果

Edge 全量 101 项、Chrome 1366 专项 10 项、生产预览 4 项通过。两种浏览器分别完成 56 次页面走查。后端 325 项通过、14 项条件跳过。前端类型检查、ESLint 和生产构建通过。 [测试记录](../../testing/T-027-craftflow-cutover.md)

## 审查与交接

独立审查核对了旧样式引用、举报页权限与链接及作品编辑会话恢复。走查修正举报页布局和加载反馈、审核筛选栏对齐，以及创作者换成买家账号时的认证提示。旧需求、会话和通知书签兼容跳转，管理员默认从 `/admin/dashboard` 进入。 [运行说明](../../../frontend/README.md)
