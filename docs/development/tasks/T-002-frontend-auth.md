## 目标与范围

实现登录、注册及找回密码页面，接入现有后端账号和会话接口。原型未单独绘制认证页面，因此沿用“拾作”的米白纸张底色、深绿主操作、陶土点缀、衬线标题及手作插画，采用品牌展示与表单并列的 PC 布局，小屏切为单列。

仅补充登录后的会话确认首页与退出入口，作为认证闭环；不实现作品列表、创作者身份切换或其他业务。QQ/163 公网收件沿用 T-001 的 SMTP 配置前提，发送失败或结果未知须如实呈现。

## 验收条件

- `/login`、`/register`、`/forgot-password` 可直接访问及相互跳转；刷新地址正常，键盘可操作，小屏不横向溢出。
- 支持 QQ/163 邮箱；注册填写昵称、最新六位验证码、密码及确认密码。昵称、密码规则与后端一致，错误就近显示，错误提交不清空用户已填写内容。
- 验证码仅在接口发送成功后提示已发送；重发说明旧码失效，失败与未知结果不假成功。
- 注册成功返回登录，不自动登录；登录后跳回合法站内原地址，禁止外部跳转；刷新从服务端恢复会话，退出后不能继续访问受保护页面。
- 找回密码成功返回登录；旧密码拒绝、新密码可用，其他设备旧会话失效后重定向登录。
- Cookie、CSRF、CORS 保持有效，不将密码或会话凭证放进本地存储、URL 或日志；网络与后端字段错误均有可读提示。
- 类型检查、ESLint、生产构建及真实前后端浏览器回归通过；公网收件未验证时明确标记。

## 设计与改动位置

- `frontend/src/layouts/AuthLayout.vue` 与 `assets/`：统一品牌外壳与原创矢量手作插画。
- `views/LoginView.vue`、`RegisterView.vue`、`ForgotPasswordView.vue`：各自表单，复用字段、密码可见性和验证码发送组件。
- `api/auth.ts`、`types/auth.ts`：对齐 T-001 的资源路径、请求 DTO 与返回 VO。
- `stores/auth.ts`、`router/index.ts`：内存会话、服务端恢复、受保护页面守卫及安全回跳。
- `utils/request.ts`：保留 CSRF 获取与 Cookie，统一保留 HTTP、业务码及字段错误；接口失败交由页面呈现。
- `frontend/e2e/`：浏览器回归及测试专用服务夹具，使用随机独立 MySQL 库和本地 SMTP；不向生产代码添加测试接口，不修改应用配置。
