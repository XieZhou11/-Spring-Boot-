## 目标与范围

实现现货及定制已完成订单的买家评价、创作者公开口碑和评价举报治理。复用 V1 评价及举报表，不修改已执行迁移。举报治理限评价对象，不扩展作品、评论或主页举报。

## 验收条件

- 仅订单买家可在订单原完成时间后七天内提交一次评价；状态须为已完成且无处理中售后或全额退款。评分 1—5 星、文字 10—500 个 Unicode 字符、图片 0—3 张。
- 服务端校验图片上传者、状态及用途；违法违规文本拒绝并保留前端输入；评价提交后不可修改。
- 公开口碑按可见且未退款的评价计算平均星级、评价数、好评率；完成订单数按存在原完成事实且当前未退款的订单统计。隐藏、删除或退款评价不参与公开统计。
- 买家评价只关联创作者，不允许创作者评价买家。公开评价可举报；同用户同评价的待处理举报合并并追加证据。
- 举报人与交易双方可按权限查看举报历史、补证或提出异议；管理员可查看评价、证据和订单会话，处理不成立/隐藏/删除，并更正结论或恢复原治理状态。所有处置留痕并通知相关用户。
- 创作者主页、报价对比和订单详情展示适用评价与口碑；评分不改变资格和排序规则。

## 设计与改动位置

- 后端新增评价/举报控制器、Service、Mapper、DTO、VO，复用订单与创作者身份、通知、操作日志、`order_review` 和举报表。
- 评价图复用现有私有图片能力，并扩展引用保护，清理任务不得删除评价或举报证据图。
- 前端订单详情提供评价入口，创作者主页展示评价及举报入口，后台增加评价举报队列和核查处置页。
- HTTP 入口包括订单评价、创作者评价列表、评价举报与证据、本人/管理员举报列表、详情、处置及更正。
